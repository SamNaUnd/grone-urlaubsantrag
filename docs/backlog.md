## Fertigstellung einer User Story

Eine User Story ist abgeschlossen, wenn:
- Die beschriebene Funktion umgesetzt ist.
- Eingaben und Berechtigungen geprüft werden.
- Relevante Tests erfolgreich sind.
- Die Dokumentation aktualisiert ist.
- Der Code geprüft und über einen Pull Request zusammengeführt wurde.
